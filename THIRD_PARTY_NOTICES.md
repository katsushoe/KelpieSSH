## Inventory Sources

This inventory records direct and transitive NuGet dependencies resolved by the eight source projects in this repository. Versions come from their `obj/project.assets.json` files; license identifiers, project URLs and copyright notices come from the corresponding package `.nuspec` metadata. The legacy `System.Memory` 4.5.3 package declares MIT in its bundled `LICENSE.TXT`. `not declared` means that the inspected metadata did not contain the field.

Test-only packages such as `xunit`, `FluentAssertions`, `coverlet.collector`, and `Microsoft.NET.Test.Sdk` are outside this runtime inventory. The build-only `Microsoft.NET.ILLink.Tasks` tool is also excluded. The resolved source-project inventory does not imply that every listed package is shipped by every product or runtime identifier.

## Redistribution Notes for KelpiePro

When redistributing KelpieSSH libraries or binaries, include the KelpieSSH `LICENSE`, this third-party notice inventory, and the applicable license and notice files from the dependencies actually included in the distribution. Dependencies added by KelpiePro require their own notices.

After a package update, restore and inspect the resolved package metadata before updating this inventory:

```powershell
dotnet list package --include-transitive
```
