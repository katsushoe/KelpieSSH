# ADR-0009: Pythonを使わないWebファイルメタデータ

## 状態

隔離環境の実SSH受入と回帰を経て、2026-10-30に採用しました。

## 背景

Webファイルのメタデータ取得はPythonに依存しています。公開結果は解決先、存在、lstatの種類・サイズ、8進権限、所有者、グループ、UTC更新日時を含みます。パス境界とリンクの既存動作を維持します。

## 決定

環境変数を初期化した固定Bashプログラムと、GNU互換のbase64・realpath・statを使用します。版付きの応答でパスとNUL区切りのメタデータをbase64転送し、ホストで型・UTF-8を検証して既存結果へ変換します。SSH標準出力65536バイト、標準エラー2048バイトに制限します。コマンド不足・非互換時は自動導入や別インタープリターへの再試行をせず失敗します。

libc互換のgetentも使用し、未知のIDと文字通りUNKNOWNという名前のアカウントを区別します。

## 代替案

Python維持では依存が残ります。シェルによるJSON生成は特殊文字の処理を複雑にします。専用リモートhelperによる取得は別の導入前提を追加します。採用案は既存のOS標準コマンドを利用します。

## 範囲と安全性

対象はメタデータです。hashは同等の代替方法を検証するまで既存のリンク追跡禁止openと記述子同一性検査を維持します。メタデータ取得では書込・内容読取を行わず、既存のサイト・SSH権限検査を通します。権限は拡大しません。GNU互換性を要求し、他実装は別途検証します。パス正規化とlstatは別操作であり、名前空間の原子的な状態取得は保証しません。

GNU tarによるhash試作は、ファイル増大時に要求した読取上限を超えたため不採用としました。statを先行納品し、hashは既存Python実装を維持します。

## 検証と運用

Python不在のDebian実SSHで18条件が合格し、監査対象13条件は違反0・試験ファイル状態不変でした。検出器の陽性対照で禁止活動4分類を検出しました。Release回帰は1101件成功・失敗0・Unix専用3件スキップです。単体試験ではprovider・MCP結果、不正応答、模擬通信異常を確認しました。これらを実機反映の根拠とし、公開リリースの許可や全OS互換性の保証とは区別します。
