# ADR-0011: Pythonを使わないWeb部分読取

## 状態

Python不在の実SSH受入と回帰を経て、2026-10-30に採用しました。

## 背景

従来スクリプトはバイト上限まで読み、バイト列の行を選択してbase64を返します。tailはopen前の観測サイズで開始位置を決めます。単純な末尾基準コマンドでは増大競合時の動作が変わり、文字列の行APIでは実バイトや行境界が変わります。

## 決定

headはGNU head、tailはGNU ddのバイト数・開始位置指定を使用します。ホストでPython互換のバイト行選択を行い、tailの行開始位置は上限付きキューで保持します。全体読取の応答構造とstatの時刻変換を再利用し、既存の2MiB通信上限の範囲でSSH受信を制限します。公開権限・引数・警告・バイト表現を維持します。

## 代替案

Python維持では依存が残ります。現在の末尾を基準にするGNU tailでは観測済み開始位置の意味が変わります。文字列への変換は不正バイトを置換し、追加の行境界も認識する可能性があります。専用リモートhelperは導入前提を追加します。固定コマンドとホスト側のバイト処理でこれらの違いを避けます。

## 範囲と安全性

設定・sudo・リモート書込は追加しません。記述子は確認しますが、正規化とopen、同時書込が原子的になるわけではありません。コマンド不足・不正応答・容量超過は代替や再試行をせず失敗します。hashと一覧は別の移行です。ツール注釈と既存MCP応答表現は変更しません。

## 検証と運用

旧Pythonのバイト処理とホスト結果を比較し、実SSHのhead/tail、CR・LF・CRLF、バイト境界、任意バイト、不在・非通常ファイル・リンク・権限、警告・モード、通信上限、期限・取消、増大/縮小の模擬条件を検証します。Python不在Linuxの非root環境と監査の陽性対照を使用します。回帰、英日シナリオ・結果、publish、保護対象の実機照合、正規Git経路での納品を行います。公開リリースは別途承諾が必要です。

CPython3.12.14とのホストprovider比較1760条件と実SSH58条件が合格しました。実行50条件は監査違反0・合成ファイル不変、8条件は実行前拒否です。独立した増大/縮小の模擬条件では、初期128バイト・上限8バイトに対するtail開始位置120を確認し、増大時は元の8バイト、縮小時は0バイトを返しました。head増大時の読取も8バイトです。回帰は1136成功・失敗0・Unix専用3件スキップでした。外部NuGet脆弱性情報は未確認であり、オフラインのビルド検証を監査成功とは扱いません。
