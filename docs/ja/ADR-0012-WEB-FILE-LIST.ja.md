# ADR-0012: リモートPythonを使わないWeb一覧取得

## 状態

採用。回帰・Python不在SSH受入・旧Python比較に合格しました。実機反映とGit納品は別途管理します。

## 背景

既存の一覧取得はメタデータの読み取りにもリモートPythonを必要とします。名前検索・本文検索も一覧取得を利用します。公開引数・権限・メタデータ・深度・打ち切り動作を維持します。

## 決定

環境を初期化した固定BashコマンドからGNU find・sort・realpath・stat・base64を使用し、数値IDの名前解決にはgetentを使用します。上限付きのbase64メタデータをフレーム形式で返し、ホスト側でJSONを構築します。既存の10秒タイムアウトに加え、標準出力2MiB・標準エラー2048バイト・標準入力0の上限を設けます。通信エラー時は途中出力を破棄します。Python・sudo・特権helperは呼び出しません。

各ディレクトリをファイルシステム順で列挙し、その階層の項目を名前順で出力した後、実ディレクトリを元の列挙順で再帰します。深度0では直下の全項目を返します。正の深度では、上限階層内の子ディレクトリとディレクトリへのリンクを出力前に除外し、ファイルとファイルへのリンクは残します。statを一括実行し、所有者・グループ名は要求内で数値ID別にキャッシュします。シンボリックリンクは再帰しません。正規化した公開ルート外を指す項目を除外します。ルート外を指す次の候補を含め、次項目の処理前に件数上限を確認し、既存の打ち切り動作を維持します。リンクのメタデータはlstat相当です。

## 代替案

- Python維持: 既存実装を保てますが導入前提が残ります。
- globだけの再帰: ディレクトリの再帰順が変わります。
- 再帰find全体のソート: 走査・打ち切り順が変わります。
- 特権helper: 読み取り専用の一覧取得に不要な権限が加わります。

## セキュリティ・運用条件

SSHユーザーの既存権限で実行します。ディレクトリ項目とメタデータだけを読み、ファイル本文の読取・書込・ネットワーク接続を行いません。走査は原子的なスナップショットではなく、同時変更により結果が変わる、または失敗する場合があります。列挙・メタデータ取得前にパスを検証しますが、可搬なパス検証は名前空間の原子的ロックを提供しません。不正UTF-8のメタデータは詳細を隠したエラーにします。BashとGNUユーティリティが前提で、不足時は明示的なエラーです。

## 影響・検証

内部一覧コマンドとホスト側デコーダーだけを変更し、一覧・名前検索・本文検索の公開schemaを維持します。hashはPythonを維持します。英日契約・シナリオ・結果を更新します。フレームとメタデータの単体テスト、旧Pythonとの比較、Python不在・非rootでの実SSH試験、読み取り専用監査、全回帰、実機反映の検証を受入条件とします。
