# ADR-0014: Web書込検査のPython不要化

## 状態

2026-11-02に、回帰・非rootのACL/パス監査・旧処理比較の合格を受け、検証済みDebian12のBash/GNU SSH範囲で採用しました。

## 背景

旧Python検査は通常/秘密経路で共有され、変更を行わない事前見込みを返します。原子的書込の成功は保証しません。

## 判断

固定Bash/GNUのメタデータ検査と、上限付きBase64パス応答を使い、C#で既存JSONへ変換します。親/対象の領域判定、リンク差、親不在時の見込み、グループ/ACL、理由、確認、helper分岐を維持します。原子的書込とhashは変更しません。

## 代替案

Python維持は読取専用機能の依存が残ります。実書込による試験は非変更要件に反します。モード値だけの判定はACL/グループ/探索の意味が変わります。追加helper導入は不要です。

## 安全性と運用

本文読取・試験書込・sudo・導入・interpreterへの自動代替を行いません。探索先/ロケール固定、環境上書き無視、通信/パス上限、既存期限/取消、安全な失敗を維持します。実ユーザーと実効ユーザーが同一の通常SSHを前提とします。文字列の実体解決は同時置換競合を排除しません。

## 実装と検証

[契約](WEB_WRITE_CHECK.ja.md)、公開tool仕様、シナリオ、結果を揃えます。非rootの所有者/グループ/ACL/探索/リンクを旧Pythonと比較し、システムコールを監査します。通常/秘密/helper応答、不正/過大応答、回帰、publish、保護データと実機、Git納品を確認します。他のユーティリティ/OSは未検証です。
