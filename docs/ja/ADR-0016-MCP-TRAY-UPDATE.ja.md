# ADR-0016: MCP管理用トレイと起動時更新

状態: 2026-11-22のユーザー依頼に基づき実装中。

## 背景
Windowsサービスはユーザーの通知領域へ表示できません。タスクトレイ、起動時自動更新、設定画面を追加しつつ、既存サービス・画面なし運用・SSH信頼境界を維持する必要があります。

## 採用判断
Windows専用KelpieMCPTrayを別プロセスとして追加します。CLIのtray/settingsと対話的起動から呼び出し、サービスのセッション0では表示しません。同じユーザー・導入先で重複常駐せず、設定画面を閉じても常駐を維持し、トレイ終了でサーバーを止めません。Designer/resxを使い、KelpieProのVPS管理画面とは分離します。

秘密のない利用者設定を導入先別LocalApplicationDataへ原子的に保存します。ログオン登録は当該ユーザー・導入先だけを所有します。SSHプロファイル・信頼ストア・サーバーの秘密設定は編集しません。

更新元はユーザー指定のGitHub Releasesです。新しい安定版の正確なMSI名、SHA-256、サイズ、HTTPSを検査します。更新処理は導入先外へコピーし、元ユーザーの調整処理と管理者権限の導入処理を分離します。既存CLIで停止・復帰し、Windows Installerを有限時間で監視します。結果不明時は自動再送・自動サーバー起動をせず、設定・鍵・利用者データを保持します。

## 代替案
サービスへ画面を組み込む案はセッション0制約により不採用です。任意の配布実行ファイルやMCP経由の自己更新権限追加は行いません。配信元を信頼するHTTPSと公式APIのダイジェストを更新元の信頼条件とし、新しい証明書固定や署名サービスは本件へ追加しません。公開操作は別途承諾が必要です。

## 影響・検証
サーバー本体はnet8.0を維持し、管理アプリだけnet8.0-windowsとします。CLI・MSI・ZIP・設定仕様と英日文書を更新します。版/資産選択、容量、ハッシュ、保存、失敗復帰、UI描画、梱包を検証します。管理画面は利用者のローカル操作であり、MCPのSSH権限や公開ツール契約は変更しません。実際の新Releaseへの更新受入と、合成のインストーラー動作確認を区別します。
