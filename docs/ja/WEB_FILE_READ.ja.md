# Webファイルの読取

`web_file_read`は通常のMCP権限検査を通し、サイトで許可された1パスを読みます。全体読取は固定BashとGNU互換の`base64`・`realpath`・`stat`・`head`、`/usr/bin/env`・`/bin/sh`・`/bin/bash`、Linuxの`/proc/self/fd`を使用します。この操作ではPythonとsudoが不要です。コマンド不足・非互換時は自動導入や別インタープリターへの代替をせず失敗します。

公開引数・サイト設定・応答項目は維持します。公開パス正規化では先頭・末尾の空白を除去し、途中の空白・引用符・日本語を保持します。ルート内リンクは対象へ解決し、ルート外への解決は拒否します。壊れたリンクを含む対象不在は`exists: false`です。通常ファイルだけを読みます。

固定コマンドは環境を初期化し、タイムアウトを10秒にします。観測サイズがサイトの`MaxReadBytes`を超えた場合は拒否し、解決先を開いた後に記述子の通常ファイル判定と解決先を確認して、最大`MaxReadBytes + 1`バイトを読みます。増大による上限超過では内容を返さずエラーにします。名前空間の原子的な状態取得や、同時書込中の一貫したスナップショットは保証しません。hash固有の同一性検査・リンク追跡禁止とは区別します。

空内容・NUL・非UTF-8を含む実バイトを正規base64で返します。既存の`encoding: utf-8`表記は維持しますが、内容の文字コード検証を意味しません。サイズは返却バイト数で、更新日時は開いた記述子から取得し、statと同じUTCマイクロ秒丸めを使用します。ホストで構造・メタデータUTF-8・時刻・base64を検証し、不正応答やタイムアウトで成功した内容を返しません。

既存の汎用SSH受信経路を維持し、別のストリーム容量制限は追加しません。固定コマンドは設定上限に応じて読取・符号化出力を制限し、ホストでも結果の長さを検証します。敵対的なリモートプログラムは、このコマンド側の上限保証の対象外です。

対象は全体読取です。先頭末尾・一覧・hash・書込は既存実装を維持します。[ADR-0010](ADR-0010-WEB-FILE-READ.ja.md)を参照してください。
