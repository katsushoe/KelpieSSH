# ADR-0013: nginxログ読取のPython不要化

## 状態

2026-11-01に、単体・隔離SSH・旧実装比較・時刻規則比較の合格を受け、Bash/GNU接続先向けに採用しました。他のユーティリティ/OS実装は未検証です。

## 背景

上限付きログ読取は、接続先時計とローカルタイムゾーンを使ってオフセットのない時刻を判定します。Windowsへ抽出を移してもWindowsの時刻規則を使ってはいけません。バイト読取にはPythonが不要ですが、datetime互換には接続先の時刻規則が必要です。

## 決定

固定Bash/GNU読取で、生ログバイト列・接続先UTC時刻・接続先TZifまたはPOSIX TZ指定を上限付きBase64で送ります。アプリケーション側で検証し、UTF-8置換復号とPython互換の行選択を行い、接続先規則で時刻を抽出します。公開スキーマ・設定キーは変更しません。既存プロファイル・パス・モード・期限の評価を維持し、行数制限後の時刻抽出・境界の等号・NUL拒否・警告マーカーを保ちます。

重複ローカル時刻は最初の出現、存在しない時刻は遷移前の差を使い、旧fold=0経路に合わせます。TZif遷移と対応済みPOSIX規則から差を計算し、非対応形式はWindowsデータへ代替せずエラーにします。接続先への時刻データ導入や時計変更は行いません。

## 代替案

Python維持は比較基準として有用ですが接続先依存が残ります。Windows時刻データは接続先と異なり得るため使いません。行ごとのdate実行は最大5000プロセスになり期限を圧迫するため使いません。専用helperは読取専用経路への新規配置が必要になるため使いません。

## 安全条件と運用

許可された正規化済み通常ログファイルだけを読みます。生データ・時刻規則・通信出力を別々に制限します。接続先のTZ選択を維持し、外部コマンド探索とロケールを固定します。アプリruntime・sudo・自動導入を使いません。不正メタデータや非対応規則は、無抽出本文を返さず拒否します。既存のパス競合制約は残り、記述子による完全な封じ込めを保証しません。

## 実装と受入

内部通信・時刻規則の解析を公開providerから分離します。バイト/文字境界、接続先時計差、数値オフセット、夏時間の重複/欠落、不正時刻、エラー対応、期限/取消を旧処理と比較します。非rootの隔離SSHでPythonあり比較とPythonなし受入を行い、英日仕様・シナリオ・結果を納品前に更新します。障害注入を実電源断の証明として扱いません。

仕様根拠: [TZif形式](https://www.rfc-editor.org/rfc/rfc9636.html)、[Python datetime](https://docs.python.org/3/library/datetime.html)。
