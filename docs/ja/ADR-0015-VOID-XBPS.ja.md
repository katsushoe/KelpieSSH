# ADR-0015: Void Linux XBPSパッケージprovider

## 状態

採用済み。provider実装と隔離環境での受入が完了しました。

## 背景

Alpine/apk・Arch/pacman・SUSE/zypperは実装済みですが、公開一覧では後者2件が未実装のままです。Void/XBPSは未対応の独立したLinuxパッケージ方式で、公式隔離イメージと非特権dry-runを利用できます。

## 判断

void/voidlinuxへ既存8操作とxbps推論を追加します。索引を自動更新せず、キャッシュ済みquery/dry-runを使います。行数上限、非0終了、プロファイルのモード/確認、sudo境界を維持し、runit対応は分離します。Arch/SUSE一覧の誤りも同じ文書変更で整合します。

## 代替案

FreeBSDは共通コマンドとVM受入の範囲が異なります。対応済み方式への別名追加だけでは新方式になりません。自動索引更新は読取専用要件に反します。

## 安全性と運用

任意フラグ・パッケージパス・鍵取込・リポジトリ編集・暗黙の全更新は許可しません。引数許可リスト・期限・既存の信頼済みプロファイル/確認を維持し、実変更は管理者設定済みsudoが必要です。キャッシュ鮮度は運用側で管理します。

## 検証と文書

選択/既定値・描画・注入・モード/確認を検証し、専用非root SSHで実XBPSの読取/dry-runとpkgdb/索引不変、合成パッケージ導入/削除を確認します。英日設定・CLI/MCP仕様・シナリオ/結果・製品版を更新し、publish/保護状態付き実機反映/Git納品/専用資産撤去まで確認します。[契約](VOID_XBPS.ja.md)。
