# Webファイルのメタデータ

`web_file_stat`はproviderが許可したパスのメタデータを返します。SSH実行前にサイトとパスの権限を確認します。解決先、存在、種類、サイズ、8進モード、所有者、グループ、UTC更新日時、リンク判定を維持します。権限操作で行うメタデータ確認も同じ読取処理を使用します。

`/usr/bin/env`、`/bin/sh`、`/bin/bash`、GNU互換の`base64`・`realpath`・`stat`、libc互換の`getent`が必要です。継承環境を初期化し、ファイル内容の読取・書込を行わず、Pythonやsudoを必要としません。コマンド不足・非互換時は自動導入や別インタープリターへの代替をせずエラーを返します。他のコマンド実装は互換性の確認が必要です。

パス正規化は既存のルート境界規則と、公開パス引数の先頭・末尾の空白を除去する動作を維持します。途中の空白は保持します。ルート内リンクはリンク自身の情報と解決先を返し、リンク先が不在でもリンクの存在を報告します。ルート外への解決は拒否します。不在パスは`exists: false`を返します。正規化とlstatは別操作であり、名前空間の原子的な状態取得は保証しません。

名前解決に該当情報がない場合、ユーザーIDとグループIDを文字列で返します。文字通り`UNKNOWN`という名前のアカウントはその名前を維持します。特殊権限ビットを含むモードと、従来の読取処理に対応するマイクロ秒丸めのUTC更新日時を返します。

固定コマンドのタイムアウトは10秒、標準出力は65536バイト、標準エラーは2048バイトに制限します。版付きbase64応答で特殊な名前を維持し、ホスト側で構造・正規base64・UTF-8・数値範囲を検証します。不正応答やタイムアウト応答を成功したメタデータとして返しません。

今回の変更はstatのみです。`web_file_hash`は既存Python実装、リンク追跡禁止open、上限付き読取、記述子同一性検査を維持します。[ADR-0009](ADR-0009-WEB-FILE-STAT.ja.md)を参照してください。
