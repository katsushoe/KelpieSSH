# Web公開ディレクトリの一覧取得

一覧取得はリモートPythonを使わず、BashとGNUユーティリティで実行します。設計と受入状態は[ADR-0012](ADR-0012-WEB-FILE-LIST.ja.md)を参照してください。hashなど未移行の操作には、それぞれの前提条件が残ります。

## 入力・設定

公開入力は`profileName`・`siteKey`・`path`・`maxDepth`（0～5、初期値0）・`limit`（1～500、初期値100）を維持します。選択したWebサイトのルートと既存の読取・パスポリシーを適用し、設定キーは追加しません。名前検索・本文検索もこの一覧取得を利用し、検索後の絞り込みや本文読取の規則は維持します。

## 結果・走査

既存の結果にはサイト情報・要求パス・解決先パス・`exists`・`entries`・`truncated`・警告・任意のエラーを返します。各項目は名前・公開ルート相対パス・解決先パス・種類・バイト数・8進数の権限・所有者・グループ・UTC更新日時・深度・シンボリックリンクフラグを維持します。名前が登録されていない所有者・グループIDは10進数文字列です。リンクのメタデータはリンク自体、解決先パスはリンク先を示します。

深度0は直下の項目を返します。再帰時は各ディレクトリ内の項目を名前順で出力した後、実ディレクトリをファイルシステムの列挙順で訪問します。要求したディレクトリの直下を深度0とします。maxDepthが正の場合、上限の深度にあるディレクトリ内ではファイルとファイルへのリンクだけを返し、子ディレクトリとディレクトリへのリンクは件数計算・打ち切り判定の前に除外します。深度0の直下一覧は別処理で、ディレクトリも返します。再帰先全体を名前順には並べません。シンボリックリンクは一覧に含めますが再帰しません。公開ルート外を指す項目は除外します。要求パスがルート内のディレクトリリンクなら、解決先から走査します。

件数上限は出力項目数で数えます。上限と同数になっただけでは打ち切り扱いにせず、その後の候補がある場合に打ち切ります。次の候補が除外対象のルート外リンクでも、既存動作に合わせて打ち切り扱いにします。存在しないディレクトリは`exists=false`と空の一覧を返します。ディレクトリ以外はエラーです。読取不可の要求ディレクトリは深度0では失敗し、再帰走査では従来どおり走査をスキップします。

## 実行・エラー

SSHユーザーの既存権限と初期化した環境で実行します。Bash・GNU base64/realpath/stat/find/sort・getentが必要です。ディレクトリ項目とメタデータだけを読み、ファイル本文は開きません。ソート用データを書込可能な一時ディレクトリへ退避せず、バッファ不足時は失敗します。sudo・helper・ファイル書込・外向き接続は要求しません。

タイムアウトは10秒、標準出力は2MiB、標準エラーは2048バイト、標準入力は0バイトが上限です。ユーティリティ不足・権限不足・不正応答・不正UTF-8メタデータ・通信上限超過は詳細を隠したエラーです。失敗時は途中出力を破棄します。キャンセルは既存のSSH契約に従います。不正な公開引数と拒否対象パスは実行前に失敗します。

結果は実行時点の走査であり、スナップショットではありません。同時変更により結果が変わる、または失敗する場合があります。正規化パス検証は既存の境界を維持しますが、名前空間の原子的ロックは提供しません。
